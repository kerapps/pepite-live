A strategy to help AI use long memory spans more effectively without extra training. It uses existing model strengths to better pick what info to remember. Current applications are mostly on experimental ground with no robust software ready yet.

Paper · arXiv

Embodied.cpp: A Portable Inference Runtime of Embodied AI Models on Heterogeneous Robots↗

Code and models to run AI on different types of robots. It helps robots get smarter without needing many different programs. The catch: it’s a paper at the moment, so expect some assembly work before it runs smoothly.

Paper · arXiv

WattGPU: Predicting Inference Power and Latency on Unseen GPUs and LLMs↗

WattGPU predicts how much power different AI models need on various GPUs. Optimizes energy use by matching the best GPUs for each model. Currently, these are predictive models — useful, but needing field validation.
